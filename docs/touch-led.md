# 上部タッチで点滅色を切り替える

K151は電源を入れると、台座のLEDが弱い青色で点滅する。上部のタッチセンサーに触れると緑色に変わり、指を離してもう一度触れると青色に戻る。上部の3区画はどこでも使える。指を置き続けた場合の切り替えは1回だけ。

点灯・消灯は約0.5秒ごとに続く。消灯中に触れた場合は、次の点灯から新しい色が出る。電源を入れ直すと青色から始まる。

## 本体で確かめる

1. 書き込み後、画面の`Minimal offline v0.2`、`Offline ready`、`Top touch: LED color`と、弱い青色の点滅を確認する。
2. 上部に触れて指を離す。緑色に変わり、点滅が続くことを確認する。もう一度触れて青色に戻ることを確かめる。
3. 上部に2秒ほど触れ続ける。色が1回だけ切り替わることを確認する。
4. 電源を入れ直して、青色から始まることを確認する。

## 検証記録

2026-11-11、Mac上で既存の初期化4項目と、色の切り替え、指を置き続けたとき、通信エラー、短いノイズ、消灯中の入力など9項目を確認した。CoreS3向けのビルドも完了した。これらのテストでは本体との通信を模擬している。

初回書き込みと同じK151であることと、復旧用ファイルのハッシュが保存時の記録と一致することを確認した。全フラッシュ消去を行わず115200bpsで書き込み、転送した4領域すべてのデータ一致を確認した。画面とタッチ動作の観察結果は確認待ち。

上部タッチにはM5StackのSi12Tドライバーを使う。読み取りの成否を確認し、通信エラーで指を離したと誤判定しない。正常に読み取れた接触状態が40ミリ秒続いたら切り替える。サーボの電源設定は[初回の最小プログラム](first-flash.md)と同じ。 [M5Stackの上部タッチセンサー資料](https://docs.m5stack.com/ja/arduino/stackchan/touchsensor)
