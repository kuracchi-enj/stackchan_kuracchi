## 本体が手元に戻ったら

1. 箱や本体の製品型番を確認する。シリアル番号・MACアドレス・QRコードは公開資料へ転記しない。
2. 標準状態で、画面が映ることと電源操作を確認する。
3. オフラインで使えるテストから、LED・タッチ・首の状態を確認する。首に抵抗があるときは手で回さない。
4. アカウントに紐付け済みなら、標準ファームウェアが動くうちに解除する。解除で会話履歴等が消えることを理解したうえで行う。
5. [復旧手順](recovery.md)に沿って、対象機種の公式ファームウェアを確保する。
6. [最小プログラムの確認手順](first-flash.md)へ進む。

この順番なら、標準機能を使い続ける必要はない。初期不良と自作プログラムの問題を切り分けるため、最初の状態だけ確認する。
